Changelog

What changed in each version of peek. To update a machine, run npm update -g @peculiarnewbie/peek there, then peek install again with the same flags.

0.2.212 November 2026Latest

New

  • Share Tailscale Serve with another app: peek pair --serve-port 8443 (or 10000) reaches peek on that HTTPS port when another app, like T3 Code, has 443. Pairing links and codes name the port, and later peek pair runs find it by themselves. Without the flag nothing changes.

0.2.112 November 2026

New

  • One command to try peek: npx @peculiarnewbie/peek pair. If peek is not running yet, peek pair now starts it in that terminal and then shows the pairing link and QR code. peek keeps running there until you close it; peek install still starts it at logon instead. Pair a browser.

0.2.012 November 2026

New

  • Windows: the login screen, the lock screen and UAC prompts. peek install --service runs peek as a Windows service, which can also see and control these, and keeps peek running while nobody is signed in. A paired browser can then do there whatever someone at the keyboard could. How to set it up.
  • Lossless text, in Settings and on by default: text and flat parts of the screen arrive exact the first time, instead of blurry and then sharp a moment later. Photos stay JPEG. Typing a character sends 238 bytes instead of 1.7 KB, and a full screen of code 84 KB instead of 219 KB. It needs peek 0.2.0 on the machine.

Fixed

  • When many scattered parts of the screen changed at once, some could stay blurry until they next changed. They are now sharpened like the rest.

This site

  • A machine's page is now at /screen/<name>. Old addresses and bookmarks still lead to it.
  • This changelog.

0.1.011 November 2026

The first release on npm.

  • A host for Windows, and for Linux on Wayland (niri, sway, Hyprland, river), that stays idle until someone looks. Any browser is the client.
  • This site: one page for all your machines, each paired once with peek pair and reached straight over Tailscale.
  • peek install starts peek at logon (Windows, as administrator, with a firewall rule) or with the graphical session (Linux). peek uninstall removes it.
  • peek logs shows what the running peek logged. peek clients and peek unpair manage paired browsers.
  • On phones and tablets: trackpad and touch modes, and a keyboard bar with a PC keyboard.
  • Windows: capture comes back after the PC wakes from sleep, and --keep-gpu makes connecting from idle faster.
