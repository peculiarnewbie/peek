peek: a small, fast remote desktop

peek is a small, fast remote desktop, tailored for short sessions.

It also lets a machine show its vitals, sleep and wake, share folders, and run plugins: programs on the machine that show up in your browser through peek.

Run it on a computer (Windows, or Linux on Wayland) on your Tailscale network and pair this browser with it once. Its screen is then a click away, with mouse, keyboard and clipboard.

This site only serves the page: your browser connects straight to each machine over Tailscale.

npx @peculiarnewbie/peek pair

How it works

  • The machine runs a small host that stays idle until you look. It captures the screen only while a browser is watching. The host runs on Windows x64, and on Linux x64 and arm64 under a Wayland compositor with the wlroots protocols (niri, sway, Hyprland, river).
  • Any browser is the client, on a computer, a phone or a tablet. There is nothing to install on the device you view from.
  • Install the host with npm install -g @peculiarnewbie/peek, then pair a browser with a one-time code. The list of your machines and their keys stay in that browser; nothing about them is sent to or stored on this site.
  • peek is free and open source, under the MIT license.
